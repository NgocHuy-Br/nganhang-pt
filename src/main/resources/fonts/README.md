# Font Directory

This directory contains fonts for PDF generation with Vietnamese character support.

## Required Font Files

Please download and place the following font files in this directory:

1. **Roboto-Regular.ttf** - For normal text
2. **Roboto-Bold.ttf** - For bold text

Download from: https://fonts.google.com/specimen/Roboto

## Alternative: Use System Fonts

If you have Arial installed on Windows, the PDF generator will automatically use:
- `C:/Windows/Fonts/arial.ttf` (Regular)
- `C:/Windows/Fonts/arialbd.ttf` (Bold)
